# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a classic word-guessing game using Python strings, loops, random selection, and user input.

## 📝 Tasks

### 🛠️ Create the Hangman Game

#### Description
Create a program that randomly selects a word and lets the player guess one letter at a time.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list
- Display the hidden word in underscore format with spaces between unrevealed letters
- Accept letter guesses from the player
- Reveal correctly guessed letters in the displayed word
- Track the number of incorrect guesses remaining


### 🛠️ Complete and Test the Game

#### Description
Add game-ending behavior and feedback so the player knows when they win or lose.

#### Requirements
Completed program should:

- End when the player guesses all letters or exhausts the incorrect guesses
- Display a clear win message and the completed word when the player wins
- Display a clear lose message and reveal the selected word when the player loses
- Ignore input that is not a single alphabetic letter and prompt the player to guess again
